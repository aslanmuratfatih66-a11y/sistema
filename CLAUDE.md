# CLAUDE.md — правила проекта «Система»

## При старте любой сессии
1. Прочитай `PROGRESS.md` (если есть) — там текущее состояние работы. Продолжай с места, где остановились.
2. Прочитай `SPEC.md` — описание проекта (источник правды).
3. Прочитай в `STAGES.md` раздел «Порядок работы» и текущий этап (номер — в PROGRESS.md).
4. Не переделывай уже сделанное без причины. Если в PROGRESS.md есть «Следующий шаг» — начни с него.

## PROGRESS.md — веди обязательно
Обновляй `PROGRESS.md` и коммить его:
- после каждого завершённого пункта этапа;
- перед каждым пушем;
- сразу, если видишь предупреждение о приближении лимита использования;
- в конце сессии.

Формат (держи кратко, до ~150 строк, старое сворачивай в «История»):

```
# PROGRESS

## Сейчас
Этап: N — <название>
Статус: в работе / собирается в CI / ждёт проверки на телефоне / завершён
Следующий шаг: <одно конкретное действие, с которого продолжить>

## Этап N — чек-лист
- [x] пункт …
- [ ] пункт … (что осталось, где именно)

## Сабагенты (текущий этап)
- A <название>: готово / в работе / не начат — файлы: …

## Решения и договорённости
- <решение> — <почему> (то, что не написано в SPEC или уточняет его)

## Известные проблемы
- <проблема> — <где> — <идеи решения>

## CI
Последний run: <ссылка> — <зелёный/красный> — <причина, если красный>
Артефакты: <ссылки на .ipa/.apk>

## Что нужно от пользователя
- <действие> (например: положить ключ в .env на сервере, проверить на телефоне)

## История
- <дата> — этап N — <одна строка итога>
```

## Общие правила
- Делай только текущий этап. Под будущие — только интерфейсы и заглушки.
- Общие файлы (pubspec.yaml, go.mod, схема БД, роутер, Info.plist, AndroidManifest, entitlements,
  workflows) правит только главный агент; сабагенты присылают нужные изменения в отчёте.
- Mac нет: проверка — сборкой в GitHub Actions (`gh run watch`, при ошибке `gh run view --log-failed`).
- Секреты не коммитить. Не выдумывать API сторонних сервисов — интерфейс + TODO.
- Коммиты небольшие, понятные, на русском или английском.
- Отвечай пользователю по-русски, коротко.
