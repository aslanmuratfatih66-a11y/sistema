# Навигация — аудит и предложение (на согласование, 2026-10-22)

## Как сейчас
Нижняя навигация: Статус · Квесты · Питание · Магазин · Ещё.
«Ещё» = экран настроек, в нём всё подряд:
- Аккаунт; План, Расписание; Напоминания, Дисциплина; Знания, Журнал ИИ, Финансы, Маркет,
  Будильники, Блокировка, Голос, Тело, Тренировки, Прогулки; оверлей персонажа; анкета; язык; данные; о приложении.
- Шестерёнка на главном ведёт туда же («Ещё»).
- Маркет дублируется: в «Ещё» и кнопкой в Финансах. Список покупок — внутри Питания.
- Тело/Тренировки/Прогулки — 2 нажатия через «Ещё», хотя это частые действия.
- Чат открывается тапом по персонажу (по решению владельца — меняется).

## Предлагаемая схема

```
Нижняя навигация:  СТАТУС · КВЕСТЫ · ЗДОРОВЬЕ · МАГАЗИН · ЕЩЁ
Поверх всех экранов: персонаж (тап — реплика; удержание 3 с — живой разговор → оттуда текстовый чат)

СТАТУС (главный, короткий)
├─ Шапка: колокольчик → Уведомления · шестерёнка → Настройки (отдельный экран, не «Ещё»)
├─ Статус: LVL → «Путь уровней» · «Очки характ.» → распределение
├─ Быстрые действия (1 нажатие): +250 мл · Еда (фото) · Тренировка · Прогулка
├─ Эффекты
├─ Следующий квест: Выполнено / +10 мин / контекстная / отказ удержанием
└─ Лента дня

КВЕСТЫ   [Сегодня | Неделя | История]
├─ Ежедневные квесты, босс недели
├─ Отметки дня: занят / пауза (§8.13), автоплан
└─ Привычки (§8.17): счётчик дней без, срыв

ЗДОРОВЬЕ   [Питание | Тренировки | Тело | Прогулки]
├─ Питание: сводка калорий, добавить еду, продукты, рецепты, добавки (§8.15)
├─ Тренировки: сегодня, программа, история, старт сессии
├─ Тело: сон, замеры, фотодневник, уход/внешность (§8.14), отёки
└─ Прогулки: старт, маршруты, карта, «магазин рядом», охота (§8.19)

МАГАЗИН   [За баллы | Покупки]
├─ За баллы: награды за ◆, архив, история
└─ Покупки: подборка ИИ под план (метка бюджета), ссылки, список покупок (переезжает из Питания)

ЕЩЁ (хаб разделов, плитки)
├─ Финансы: сводка сверху + «+ Расход» · чек · банки · выписка · отчёты/цели/подписки/долги
├─ Мой план · Расписание
├─ Знания (курсы)
├─ Будильники · Блокировка приложений
├─ Друзья и рейтинг (§8.18, позже) · Бестиарий (§8.19, позже)
├─ Журнал ИИ (действия и расходы)
└─ Настройки →

НАСТРОЙКИ (шестерёнка на главном или последняя плитка «Ещё»)
├─ Аккаунт и синхронизация
├─ Анкета (разделы)
├─ Квесты: напоминания, дисциплина, режимы дня (автоплан, адаптивная сложность)
├─ Персонаж и ИИ: голос, оверлей Android, параметры покупок (магазины, бюджет)
├─ Музыка (§8.20, позже) · Подключения (§8.10, последний этап)
└─ Язык · Данные (экспорт/импорт/сброс) · О приложении
```

## Глубина частых действий

| Действие | Сейчас | Будет |
|---|---|---|
| Выполнить квест | 1 | 1 |
| Вода +250 | через квест | 1 (быстрое действие) |
| Записать еду | 2 | 1 (быстрое) / 2 |
| Начать тренировку | 2 (Ещё) | 1 (быстрое) / 2 |
| Начать прогулку | 2 (Ещё) | 1 (быстрое) / 2 |
| Записать сон/замер | 3 | 2 |
| Купить награду | 2 | 2 |
| Записать расход | 3 (Ещё → Финансы → …) | 2 (Ещё → «+ Расход») |
| Подборка покупок | 2–3 | 2 (Магазин → Покупки) |
| Путь уровней | — | 1 (LVL) |
| Поговорить с ИИ | 1 (тап) | удержание 3 с |
| Настройки | 1 | 1 (шестерёнка) |

## Вопросы к владельцу
1. «Здоровье» с переключателем вместо «Питания» — ок? (Альтернатива: оставить «Питание», а Тело/Тренировки/Прогулки — плитками в «Ещё».)
2. Набор быстрых действий на главном: +вода, еда, тренировка, прогулка — ок или заменить?
3. Финансы в «Ещё» со сводкой и «+ Расход» сверху — ок, или нужна отдельная вкладка (тогда что-то уходит из нижней панели)?
