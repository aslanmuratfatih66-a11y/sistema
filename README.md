# Система

Личное RPG-приложение квестов: Flutter-клиент (`app/`), сервер на Go (`server/`), деплой (`deploy/`).
Описание — `SPEC.md`, этапы — `STAGES.md`, текущее состояние — `PROGRESS.md`.

## Предпросмотр

Приложение можно смотреть в Chrome в рамке телефона, без Mac и без телефона. Изменения кода видны сразу (hot reload).

```bash
cd app
flutter run -d chrome -t lib/main_preview.dart
# Android по умолчанию: --dart-define=PREVIEW_PLATFORM=android
# Баннер сертификата iOS: --dart-define=PREVIEW_CERT_DAYS=2 (отрицательное — уже истёк)
```

Клавиши в терминале, где запущен `flutter run`:

| Клавиша | Что делает |
|---|---|
| `r` | hot reload — подхватить изменения кода, состояние экрана сохраняется |
| `R` | hot restart — перезапустить приложение с нуля (данные в браузере остаются) |
| `q` | выход |

Горячие клавиши в окне Chrome (кликните по странице, чтобы она была в фокусе):

| Клавиши | Что делает |
|---|---|
| `Alt+1` / `Alt+2` / `Alt+3` | iPhone 15 Pro / Pixel 9 / Galaxy S25 |
| `Alt+L` | язык ru ↔ tr |
| `Alt+T` | размер шрифта 100% → 130% → 150% |
| `Alt+R` | сбросить демо-данные (очистить и засеять заново) |

Полный тулбар device_preview (любое устройство, ориентация, тема, клавиатура, скриншот) — во Flutter DevTools,
вкладка **device_preview** (ссылку на DevTools печатает `flutter run`).

Ограничения:
- нативное — заглушки: уведомления, будильник, геолокация (точка в Москве, прогулка «понарошку»), камера,
  шаги, TTS и распознавание речи, Live Activity/виджеты, банки, оверлей, блокировка приложений, Face ID/PIN;
  набор возможностей (`CapabilityService`) — как у платформы выбранного устройства;
- ИИ и сервер не подключены: ИИ-функции работают на шаблонах, курсы и уроки — из шаблона;
- данные демонстрационные, засеваются при первом запуске и хранятся в браузере (IndexedDB) — между запусками
  сохраняются; `Alt+R` возвращает исходный набор;
- оформление iOS/Android (Cupertino/Material) переключается только в debug-запуске.

Код предпросмотра — `app/lib/main_preview.dart` и `app/lib/preview/`. В релизную сборку не попадает:
точка входа телефона `app/lib/main.dart` их не импортирует.
